### Patch 2 — Regex precio v2

Bug reproducido: el texto del carousel item `"threezero Figura a escala 1:6 de Robo-Dou$\xa0410.420,311001hobbies.esy más5,0(2)"` produce match `$\xa0410.420,311001` con el regex actual `(?:\$|ARS|U\$S)\s?[\d](?:[\d.,]*\d)?`. El cuantificador `[\d.,]*\d` es greedy: cuando `1001hobbies.es` viene pegado sin separador después de `,31`, los dígitos `1001` se absorben.

```diff
-_PRICE_RE = re.compile(
-    r"(?:\$|ARS|U\$S)\s?[\d](?:[\d.,]*\d)?",
-    re.IGNORECASE,
-)
+# AR price: $X.XXX,XX (con miles + 2 decimales OBLIGATORIO para evitar bleeding
+# en texto concatenado como "$410.420,31" + "1001hobbies.es"). Alt acepta
+# entero sin separadores (ARS 5000, U$S 5000) con lookahead negativo.
+_PRICE_RE = re.compile(
+    r"(?:\$|ARS|U\$S)\s?(?:&nbsp;)?\s?"
+    r"(?:"
+    r"[1-9]\d{0,2}(?:\.\d{3})*,\d{2}"
+    r"|"
+    r"[1-9]\d{2,7}(?![\d.,])"
+    r")",
+    re.IGNORECASE,
+)
```

### Patch 3 — `_extract_pla_unit()` + nuevo pass

Prototipo validado en `/tmp/parser_v2.py` (4 productos extraídos del fixture robotech, 30 del fixture zapatillas, 0 false positives). Código a copiar:

```python
# ── Shopping panel (pla-unit) — sponsored ads con URL canonical real ──
PLA_SELECTORS = ["div.pla-unit"]


def _extract_pla_unit(node) -> dict | None:
    """Extract product from Google Shopping pla-unit cell.
    Returns None if no real URL or no title (carga incompleta).
    """
    th = node.css_first("[role=heading]")
    title = th.text(strip=True) if th else None

    # Skip /aclk? redirects — they're display:none tracking pixels. Pick the
    # first http link that's NOT an aclk: it's the product URL with merchant params.
    href = None
    for a in node.css("a[href]"):
        h = a.attributes.get("href", "")
        if h.startswith("http") and "/aclk?" not in h:
            href = h.split("&amp;")[0]
            break
    if not href or not title or "google.com" in href:
        return None

    price_el = node.css_first("span.VbBaOe")
    price = price_el.text(strip=True).replace("\xa0", "") if price_el else None

    store_el = node.css_first("div.UsGWMe")
    store = store_el.text(strip=True) if store_el else None

    inst_el = node.css_first("div.OkcyVb")
    inst = inst_el.text(strip=True).replace("\xa0", "") if inst_el else None

    return {
        "url": href,
        "title": title,
        "snippet": None,
        "price_in_card": price,
        "has_price": bool(price),
        "store_hint": store,
        "installments": inst,
        "flags": ["pla_unit", "sponsored"],
    }
```

## 3. Hipótesis cerradas — no abrir de nuevo

- **Carousel URLs sin JS NO son recuperables.** Solo hay 7 URLs canónicas en HTML para 30 carousel items. Fuzzy match título→slug da 26% false positives. Las URLs reales viven en el `data-ved` blob protobuf firmado por Google. Workaround actual (synthesize `google.com/search?q=Title+site:Store`) es lo mejor sin JS-render adicional. No tocar en esta phase.

- **Cloak SÍ hace JS-render** (es Playwright stealth real). El bottleneck es `wait_until="domcontentloaded"`, no la naturaleza de Cloak. Fix con D-01 sin cambiar arquitectura.

- **Selector primary `MjjYud div.tF2Cxc` NO está perdiendo precios reales.** Los 3 wrappers `MjjYud` directos con precio detectado son duplicados del carousel — correcto saltearlos.

## 5. Riesgos identificados + mitigación

| Riesgo | Probabilidad | Mitigación |
|---|---|---|
| Google rota la clase `div.pla-unit` | Baja (clase semántica estable años) | Selector contenedor `div.pla-unit` es el más resistente; fallback silencioso si rota (D-11) |
| `wait_until="load"` aumenta p99 latency | Baja (1 sample mide -2.3s en robotech) | Timeout bajado a 15s para fail-fast; smoke runtime confirma p95/p99 |
| Las clases internas (`VbBaOe`, `UsGWMe`, `OkcyVb`) rotan | Media (Google las rota ~trimestre) | Aceptable: si rotan, perdemos pla-units pero NO el resto; signal via D-11 log |
| El test fixture pesa demasiado en repo | Alta sin filter | D-12 mitigación: strip base64 images |
| Regex v2 rechaza precio válido edge case | Baja (10 casos validados) | Tests adicionales si aparece regression |
| Endpoint `/admin/parity/<query>` expone info sensible | Media sin auth | X-API-Key + role check `admin_audit` (D-15) |
