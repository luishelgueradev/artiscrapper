## Decisions Made

- **Source rename `l → line` over per-file-ignores** (per RESEARCH Open Question 2 + Anti-Patterns): a 1-letter delta is cheaper than the lifetime cost of losing regression lint coverage if any spike script is ever revived for a Phase-1-style validation cycle. The chosen iterator name `line` also matches the existing convention at `09_label_cards.py:394` (`for line_no, line in enumerate(lines, ...)`), avoiding mixed conventions inside the same file.
- **F841 surgical resolution** (per RESEARCH Assumption A2): LHS-drop where the RHS has a side-effect (`await`, `raise`), whole-line delete where the RHS is pure (`= None`, `= statuses.count(...)`). Conservative: do not assume; review each site.
- **No `_` prefix shortcut** (per RESEARCH Open Question 2): `_results = await smoke(...)` would suppress F841 but lose the convention that all real bindings in spike-replay scripts use descriptive names. The LHS-drop pattern produces equivalent semantics without the prefix.
- **Deviation Rule 3 — delete residual `import cloakbrowser as _cb`** (1 F401 surfaced post-auto-fix): the symbol `_cb` is never referenced; the `from cloakbrowser import launch_async  # noqa: F401` line below it serves the same import-probe purpose for the ImportError detection. Required for ruff-zero.
- **Deviation Rule 3 — LHS-drop `parsed = json.loads(content)` in try-branch**: surfaced because once `parsed = None` was removed from the except-branch, ruff's flow analysis narrowed and newly flagged the try-branch binding as dead. The call `json.loads(content)` is preserved to retain the raise-on-malformed-JSON contract that drives the `except json.JSONDecodeError: json_ok = False` path.
