## Decisions Made

1. **ALWAYS-ON deprecation gate, not CI-only** — per RESEARCH Open Question 1 lock and the plan's `must_haves.truths`. Encoding `filterwarnings = ["error::DeprecationWarning"]` in `pyproject.toml` (not just CI workflow) means local `pytest` invocations behave identically to CI, eliminating the "passes locally, fails in CI" regression class.
2. **Zero narrow ignores added** — the escalation gate defined in Task 2's action block (which would have required pausing + operator approval for any narrow `ignore::DeprecationWarning:offending.module`) did not fire. No third-party transitive emitted a new DeprecationWarning after the httpx2 install, so `SC#3` passes cleanly with the gate at its strictest setting.
3. **Verification-method deviation on AC#5** (Author-email + Project-URL grep) — used `METADATA` file directly because modern uv venvs do not install standalone `pip` (`.venv/bin/pip` doesn't exist). The data source `pip show` reads from IS `METADATA`; the criterion semantics — "both facts present, both non-negotiable" — are preserved. See Deviations §1.
