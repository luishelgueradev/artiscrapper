## Decisions Made

- **Captured via docker exec into the running container (not local venv).** The worktree's `.venv` lives at `/home/luis/proyectos/artiscrapper/.venv` (main repo, outside worktree) and Cloak + Playwright browser binaries are guaranteed-installed inside the artiscrapper image. `docker compose exec` route succeeded on the first attempt with both fixtures cleanly captured. Avoided the autonomous-overnight fallback tree (synthesis → hand-rolled HTML) entirely.
- **Force-degraded-mode test pattern via `monkeypatch(router_health_check → False)`** instead of stubbing `curate_candidates`. Three reasons: (1) `curate_candidates` has a non-trivial signature (`tuple[list[dict], int, bool]` plus Semaphore + httpx.AsyncClient orchestration internally); (2) the plan explicitly allowed this fallback ("the executor should adapt … OR skip the curator/visit monkeypatching and rely on the real LLM router being down → degraded mode"); (3) the test surface we care about for paginación is fetch count + dedupe + metadata, none of which depend on the LLM curator's specific behavior.
- **`visit_candidates` stubbed as a no-op passthrough.** Signature is simple (`async def visit_candidates(candidates, visit_timeout_s=10) -> list[dict]`) so a 2-line stub is enough. Avoids real httpx network calls that would otherwise try to visit candidate URLs from the fixtures.
- **Cross-test contract followed exactly** — env-vars-before-import + API_KEYS refresh + challenge_backoff state reset + slowapi limiter reset. This mirrors the patterns in `test_rate_limit.py`, `test_degraded_mode.py`, and `test_challenge_backoff.py` so the new file is robust to test-collection ordering (sibling test files can import `app` first without breaking us).
- **Unique query strings per test** (e.g. `page2-pages2-probe-termotanque`) so the cache layer doesn't return a sibling test's prior response from this session.
- **Dedupe assertion is self-correcting.** Instead of hardcoding an expected count (e.g. "37"), the dedupe test computes `expected_unique = len(dedupe(parse_serp(page1)))` at test time. If `pla_unit_robotech.html` is re-captured in a future phase, the assertion bound updates automatically.
- **No production code touched.** Plan 02 is purely test+fixture+script artifacts — the Plan 01 wire-in already shipped the behavioral change, and Plan 02 is the regression net pinning it.
