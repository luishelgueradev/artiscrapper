<objective>
Close TECHDEBT-02: remove the deprecated `default_response_class=ORJSONResponse` configuration from the FastAPI app object in `src/artiscrapper/main.py` and the now-unused `from fastapi.responses import ORJSONResponse` import. Rely on FastAPI 0.136.3's native Pydantic-Rust serializer (the framework-blessed fast path per PR #14964) for the one `response_model=SearchResponse` route.

Purpose: FastAPI 0.131+ deprecates `ORJSONResponse` because Pydantic v2's Rust serializer is now the default fast path for `response_model` routes. PR #14964 confirms removal is not a regression — for `POST /search` (the only perf-critical route), the Pydantic-Rust path is FASTER than the wrapped ORJSONResponse path. For the 3 dict-returning routes (`/health`, `/health/deep`, `/admin/parity/{q}`), the delta is below measurement noise on small payloads. Removing the kwarg eliminates a `FastAPIDeprecationWarning` and removes one layer of indirection.

Output: `src/artiscrapper/main.py` line 28 (`from fastapi.responses import ORJSONResponse`) DELETED; line 245 (`default_response_class=ORJSONResponse,` inside the `FastAPI(...)` call) DELETED.
