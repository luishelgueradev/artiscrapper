# Plan 0.2.1-01 — Parser core fixes — Summary

## Goal

Apply the 3 quirurgic patches from `.planning/PARSER-VISUAL-PARITY-2026-06-05.md` (Estrategia A) to close the empirically-measured gap of `+207% URLs reales perdidas` in the SERP parser.

## What was built

### 1. `src/artiscrapper/browser.py` — switch `wait_until` (PARITY-01)

`page.goto()` now uses `wait_until="load"` (was `"domcontentloaded"`) and `timeout=15_000` (was `20_000`). The change recovers the Google Shopping panel (`div.pla-unit`) which the prior setting cut off before render. Per the report's empirical comparison, `load` finishes faster on average in this sample (3.3s vs 5.6s) — no latency penalty, +4 pla-units captured per query in robotech, +20 across the 5-query dataset.

D8 invariant (no persistent contexts) preserved unchanged. `_detect_block`, `BLOCK_MARKERS`, and `fetch_serp` signature unchanged.

### 2. `src/artiscrapper/search.py` — `_PRICE_RE` v2 (PARITY-03)

Replaced the greedy regex `(?:\$|ARS|U\$S)\s?[\d](?:[\d.,]*\d)?` with a closed pattern that requires either:
- thousands form with mandatory `,DD` closure: `[1-9]\d{0,2}(?:\.\d{3})*,\d{2}` — matches `$1.397.000,00`, `$5.000,00`, etc.
- integer with negative lookahead: `[1-9]\d{2,7}(?![\d.,])` — matches `ARS 5000`, `U$S 5000`.

Closes the bleeding bug demonstrated in carousel text `threezero ... Robo-Dou$ 410.420,311001hobbies.es` where the old regex absorbed the `1001` from the store name. Validated against 10 cases from the report; all 9 pre-existing parser tests pass without regression.

### 3. `src/artiscrapper/search.py` — `_extract_pla_unit` + `PLA_SELECTORS` (PARITY-02)

New standalone extractor for Google Shopping Product Listing Ad cells. Each cell exposes:
- Title in `[role=heading]` (NOT the empty aria-label of the wrapping `<a>`)
- Canonical merchant URL in the first `<a>` that's NOT `/aclk?` (those are display:none tracking pixels)
- Price in `span.VbBaOe` (NBSP stripped)
- Store hint in `div.UsGWMe`
- Optional monthly installment in `div.OkcyVb`

Returns `None` on partial HTML — graceful degradation when Google rotates the internal obfuscated classes (`VbBaOe`, `UsGWMe`, `OkcyVb`).

### 4. `src/artiscrapper/search.py` — pla-unit pass in `parse_serp()` (PARITY-02)

New loop appended after the existing carousel loop. Aditivo, not replacement:
- Organic cascade still runs first (with `parse_cascade_exhausted` warning unchanged)
- Carousel loop still runs second (synthetic URLs unchanged)
- Pla-unit loop is third and last, dedupes internally by URL
