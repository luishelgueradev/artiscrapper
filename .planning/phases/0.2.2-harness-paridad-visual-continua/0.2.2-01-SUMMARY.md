nightly script.

### 3. `src/artiscrapper/metrics.py` — 3 new families (HARNESS-02)

Beside the 2 existing Phase 0.2.1 gauges:

```python
parity_coverage_pct = Gauge(
    "artiscrapper_parity_coverage_pct",
    "Real-URL coverage percent (clamped 0..100) for the last audited query",
    ["query"],
)
parity_pla_units_missed = Counter(
    "artiscrapper_parity_pla_units_missed_total",
    "Total pla-units present in HTML but missed by parser (drift signal)",
    ["query"],
)
parity_url_synthetic_ratio = Gauge(
    "artiscrapper_parity_url_synthetic_ratio",
    "Fraction of candidates whose URL is a Google synthetic (carousel)",
    ["query"],
)
```

`Gauge` vs `Counter` per Prometheus idioms: Counter for "did X happen N
times?", Gauge for "what is the current state?".

### 4. `src/artiscrapper/main.py` — dataset loader + shared helper

- Module-level YAML load into `_PARITY_DATASET: dict[str, dict]`, keyed by
  `query.strip().lower()` for O(1) lookup. Load failure logs
  `parity_dataset_load_failed` warning and leaves dict empty — production
  keeps working without coverage_pct.
- `_compute_parity_metrics(query, html, candidates, pla_nodes_count)` —
  single source of truth for the 5 parity metrics. Returns the new
  `coverage` block. `admin_parity` endpoint refactored to delegate to it.
- JSON response shape extended: `coverage` block added alongside the
  existing keys. No breaking change (additive only).

### 5. `tests/test_parity_harness.py` — 5 unit tests

All passing. Coverage:

- `test_dataset_yaml_loads_and_validates_schema` — schema soundness (12 entries, required keys, valid specificity values)
- `test_dataset_loaded_into_main_module` — module loader populates `_PARITY_DATASET` correctly at import
- `test_set_parity_metrics_computes_coverage_pct_correctly` — formula validation + url_synthetic_ratio
- `test_set_parity_metrics_increments_missed_counter` — Counter `inc()` works with exact diff
- `test_set_parity_metrics_handles_unknown_query_gracefully` — None coverage_pct + no crash for prod queries
